## About the Project

This project aims to keep Cyberpunk RED alive and thriving on modern Foundry versions. It brings full compatibility with **Foundry VTT v14**, integrated community bug fixes, UI/UX polish, and system optimizations.

This is an ongoing development effort. While we aim for a smooth and stable experience, edge cases and bugs may occur. If you run into issues or have ideas for improvements, please [open an issue on GitHub](https://github.com/HeiseiRei/FVTT-Cyberpunk-RED---next/issues) — community feedback is always welcome!

## Installing

The easiest way to install the system is via the Foundry VTT Game System manager:

1. Launch Foundry VTT and go to the **Game Systems** tab.
2. Click **Install System**.
3. Paste the following **Manifest URL** into the field at the bottom:

```text
https://github.com/HeiseiRei/FVTT-Cyberpunk-RED---next/releases/latest/download/system.json
```

4. Click **Install**. Foundry will download the system and use this manifest to automatically notify you of future updates.
